# TFT Boost

App Android tối ưu 1 chạm trước khi chơi Đấu Trường Chân Lý Mobile trên Galaxy S25+.

- Mức cơ bản: dọn tiến trình nền, bật Không làm phiền, mở game.
- Mức nâng cao (cần Shizuku): buộc dừng app nền, Game Mode performance, hiệu năng cố định, ép 120Hz, tắt GOS, biên dịch tối ưu game.

Build: GitHub Actions tự chạy khi đẩy mã (`.github/workflows/tft-boost.yml`), APK nằm ở mục Releases.
Build tay: mở thư mục `tft-boost` bằng Android Studio rồi chọn Build > Build APK.
